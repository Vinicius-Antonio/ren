# Base de Conhecimento da Ren

Coloque nesta pasta (`knowledge/`) qualquer arquivo `.md` ou `.txt` com anotações, documentações de projetos, listas ou informações que você queira que a **Ren** conheça.

- Arquivos curtos são resumidos automaticamente no início da conversa.
- Arquivos maiores podem ser pesquisados pela Ren em tempo real durante a conversa usando a ferramenta `search_local_knowledge`.
